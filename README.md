# 软件世界模型

为完全零基础读者写的软件原理知识库：先看熟悉的动作，再理解机制，最后认识技术名称。

**[在线阅读](https://zhongky1995.github.io/software-world-model/)** · [从总地图开始](content/00-world-map.md) · [按名词查找](content/08-reference/glossary.md)

## 里面有什么

29篇文章、9张机制图和全文搜索，连接计算与运行、数据与状态、通信与协作、边界与架构、可靠性与信任、演进与交付、AI软件。

第一次建议阅读：总地图 → 程序 → 运行 → 状态 → 前后端 → 分工 → AI模型。所有文章都可以直接打开，不需要练习、打卡或背词表。

## 离线阅读

下载或克隆仓库，直接用浏览器打开 `site/index.html`。正文、搜索和图解都在这个文件内，阅读无需联网；外部资料链接需要联网。

## 修改与构建

需要 Node.js 22 或更新版本。

```sh
npm ci
npm test
npm run build
npm run check
```

- `content/`：可编辑的文章与SVG图解。
- `app/catalog.json`：文章目录、标题与关联入口。
- `app/term-definitions.json`：概念与英文搜索别名。
- `app/reader.html`：阅读界面模板。
- `scripts/`：Markdown验证、构建和产物检查。
- `site/`：构建好的离线阅读页面。

如果修改正文，运行构建命令后再打开阅读页。`main`分支更新后，GitHub Actions会构建并部署GitHub Pages；提交PR时只检查构建，不发布。
